## المصادر وحقوق الاستخدام

مرجع الحزمة المعلن هو [موقع كود المنصات](https://design.dga.gov.sa/). الروابط التفصيلية والأدلة والتواريخ موجودة داخل المرفق. النسب إلى المصدر لا يعني اعتمادًا منه أو نقل حقوق جميع المواد الموجودة فيه.

الأرشيف يجمع ملفات دراسة وأدوات ولقطات لموقع يحتوي مواد أطراف متعددة. لم يُرفق به ملف ترخيص جامع؛ لا يمنح هذا التغليف ترخيص MIT للمحتوى، ولا يزيل إشعاراته. إتاحة مادة للعرض العام لا تحدد وحدها شروط إعادة استخدامها.

- يتضمن JS الملتقط إشعارات مكونات متعددة، ومنها `@hugeicons/react-pro`. راجع [شروط Hugeicons](https://hugeicons.com/docs/faqs/license-questions) قبل استخراج الأيقونات أو إعادة استخدامها؛ لا تعامل bundle الموقع كحزمة أصول للاستخدام في منتجك.
- يتضمن CSS الملتقط خطوط IBM Plex. عند حاجة مشروعك للخط، استخدم التوزيع الرسمي مع [ترخيص IBM Plex](https://github.com/IBM/plex/blob/master/LICENSE.txt) وإشعاراته بدل نسخ CSS الملتقط.
- الصور والشعارات وfavicon تخص سياق المصدر؛ ليست هوية جاهزة يحق نسبتها إلى كل مشروع.
- ملفات `critical.css` و`non-critical.js` و`sitemap_index.xml` داخل اللقطات هي نسخ HTML لغلاف التطبيق وليست الأنواع التي تشير إليها أسماؤها. لا تستخدمها كتلك الأنواع.

احتفظ بالمرفقات للمراجعة والتتبع، واقرأ إشعارات وشروط كل مادة قبل استخدامها في مشروع آخر. لا يحتاج تدقيق Python أو تخطيط الترحيل إلى تنفيذ أو استخراج حزم الموقع وأصول هويته.
