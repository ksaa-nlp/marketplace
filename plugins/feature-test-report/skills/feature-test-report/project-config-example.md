# إعدادات المشروع لمهارة feature-test-report

انسخ هذا الملف إلى `.claude/feature-test-report.md` في مشروعك واملأ ما ينطبق. كل الأقسام اختيارية؛ ما تتركه تستنتجه المهارة من المستودع. احذف الأقسام التي لا تحتاجها.

## Specs

أين مواصفات الميزات، الأخص أولًا.

- `docs/specs/<feature>.md`

## Tests

أنماط الملفات التي تُعدّ اختبارات، ومكان اختبارات end-to-end.

- `src/**/*.test.ts`
- `e2e/**/*.spec.ts`

## Commands

كيف تُشغَّل مجموعة جزئية من الاختبارات، ومن أي مجلد.

| المجال | الأمر                   |
| ------ | ----------------------- |
| unit   | `npm test -- <pattern>` |
| e2e    | `npx playwright test`   |

## Roles

الأدوار التي تُكتب لها سيناريوهات الوصول.

- guest, signed-in user, owner, admin

## Known traps

ما يجعل نتيجة التشغيل تبدو على غير حقيقتها.

- الاختبارات التي تمسّ قاعدة البيانات تحتاج `DATABASE_URL`؛ بدونه لا تُحمَّل المجموعة.

## Report

- المجلد: `docs/test-reports/`
