# التكييف مع تقنية المشروع وخطة القبول

هذه تعليمات لإنتاج تكييف جديد، وليست شفرة Vue أو Angular أو JavaScript مستقلة مختبرة. الحالة الحالية: مرجع React V5 مع Tailwind هو التنفيذ الوحيد المختبر. قبول التكييف يحتاج أدلة من المشروع الذي يُدمج فيه.

## حدّد مسار التنفيذ

| المشروع الذي وجدته | مسار العمل |
| --- | --- |
| React مع Tailwind | افحص توافق التصميم ثم ادمج المرجع، وراجع دليل react-reference.md. |
| إطار آخر للعميل | استخدم مكوّناته وحالته ودورة حياته وآلية الرسم خارج حاويات المحتوى المفلترة. لا تضف React للقدرة على استيراد TSX. |
| HTML/CSS/JavaScript ثابت | أنشئ دلالات DOM وأحداثًا وأنماطًا وفق بنية المشروع، مع تنظيف المستمعات والحالة. استخدم SVG أو أيقوناته المتاحة. |
| صفحات من الخادم أو SSR | أخرج الدلالات المناسبة من نظام القوالب، ثم اربط السلوك في العميل بعد توفر DOM. افحص الانتقال بين الصفحات أو الترطيب. |

قد يجمع المشروع أكثر من مسار؛ اتبع البنية التي وجدتها. لا تغيّر الإطار أو نظام CSS لمجرد محاكاة المرجع.

## موارد الحزمة والاعتماديات

احتفظ بـSKILL.md ومجلدي assets وreferences معًا. ملف TSX وCSS والاختبارات موارد مرجعية محلية. المكتبات الخارجية وnode_modules ليست داخل ZIP. تحتاج مكتبات React/ReactDOM وTailwind وLucide فقط عند اختيار التنفيذ المرجعي؛ في التكييف الآخر استخدم ما هو موجود، وأضف اعتمادًا جديدًا فقط إن كان له سبب واضح.

## خطوات التنفيذ

1. دوّن الإطار والإصدارات ونظام CSS والتوكنات وطريقة العرض والمسارات وسياسة CSP وأدوات الاختبار التي وجدتها.
2. حوّل المتطلبات في SKILL.md إلى حالة وسلوك DOM وفق المشروع. حدّد طبقة الحوار والدليل ومحتوى الموقع الذي يمكن تخصيصه دون المساس ببنيته.
3. نفّذ الأزرار والحوار والتركيز وعزل الخلفية أولًا؛ ثم النص والتدفق، ثم الدليل والحفظ والفلاتر والنطق والوسائط.
4. اعزل fixture أو mocks عن الشفرة التي تُسلّم. لا تستخدم speak mock لإعلان نجاح صوت مسموع ولا محاكاة viewport لإعلان اختبار لمس فعلي.
5. اختبر الجدول التالي مع الأدلة، ثم سلّم التكييف وتسميات الوظائف غير المتاحة وحدود النتائج. لا تنشر الموقع إلا وفق طلب المستخدم.

## خطة القبول

طبّق كل حالة ذات صلة. الحالة التي لم تُنفّذ لا تُسجَّل نجاحًا؛ سجّل السبب والخطوة اللازمة لاستكمالها. أضف حالات المشروع الخاصة ومقارنة تقرير المرجع إذا احتجت تفاصيل أكثر.

| الحالة | خطوات التكرار | المطلوب والدليل |
| --- | --- | --- |
| طريقة العرض ودورة الحياة | شغّل البناء/فحص الأنواع المناسبين؛ افتح الصفحة، غيّر المسار أو أزل وركّب الأداة وفق المشروع. | لا أخطاء DOM أثناء SSR، ولا تكرار طبقة أو مستمعات؛ استعادة عزل الخلفية وإلغاء النطق عند الإزالة. |
| الفتح | Tab إلى الفتح ثم Enter؛ أعد بـSpace ثم بالمؤشر. | اسم واضح وتركيز مرئي وحالة توسع صحيحة وانتقال التركيز للحوار. |
| السحب | اسحب الزر أكثر من العتبة ثم اتركه؛ جرّب Alt + الأسهم. | يتغير الموضع دون فتح عرضي، ويتاح بديل بلوحة المفاتيح. |
| التركيز والإغلاق | افتح، جرّب Escape ثم زر الإغلاق ثم الغطاء، والإخفاء والإظهار. | يعود التركيز للفتح/الإظهار؛ النقر لا يفعّل عنصر خلفية. |
| Tab وعزل الخلفية | جرّب الاتجاهين ودورة Tab؛ حاول تركيز خلفية مغطّاة، وأضف عنصرًا عند الفتح، ثم أغلق. | التركيز داخل الحوار، والخلفية معزولة وتستعيد حالتها السابقة. افحص بقارئ شاشة فعلي أيضًا. |
| اختيار الإعدادات | استخدم Tab وEnter/Space ومفاتيح select المناسبة. | تسميات وحالات وقيم مفهومة، دون اعتماد على المؤشر فقط. |
| التدفق والتكبير | 320 و375px، سطح مكتب، تكبير متصفح 200% و400%، تكبير صفحة مع A+، ونص حتى 180%. | الأزرار والقياس لا تتداخل ولا تتجاوز أفقيًا؛ سجّل أبعاد client/scroll وحدود التركيز. |
| الموضع المحفوظ | احفظ الموضع قرب الحافة على سطح المكتب ثم صغّر إلى هاتف وأعد التحميل. | الزر داخل الشاشة وفق أبعاده الفعلية. |
| ADHD والدليل | فعّل preset وأغلق اللوحة؛ استخدم المؤشر وTab والتحديد ثم reload وReset. | دليل مرئي يتبع موضع القراءة/التركيز، وحفظ صحيح، ووصف غير طبي. |
| النطق ودورة الإيقاف | بصوت عربي فعلي: تشغيل ثم pause/resume/stop وReset أثناء النطق. | أوامر وأحداث المحرك صحيحة، وإيقاف متاح، ولا ضياع تركيز. سجل جودة الصوت باختبار استماع منفصل. |
| ثبات التحديد | فعّل قراءة التحديد، حدد نصًا، ثم Tab دون تغييره؛ غيّره بعدها. | لا إعادة نطق للتحديد نفسه؛ التحديد الجديد يُقرأ وفق الإعداد، ويمكن إيقافه. |
| تقليل الحركة | اختبر خيار الأداة وتفضيل النظام، والتمرير والنطق والحركات في الموقع. | مدة وسلوك الحركة والتمرير يطابقان نطاق الوظيفة المعلن، مع استعادة إعداد الاختبار السابق. |
| حفظ التفضيلات | غيّر إعدادات ثم reload؛ جرّب تخزينًا غير متاح أو بيانات غير صالحة وReset. | حفظ أو fallback واضح لا يعطّل الأداة؛ النطق والعلامات والإعدادات تُعاد وفق العقد الموثق. |
| كتم الوسائط | اكتم audio/video يدويًا ثم غيّر حجم النص؛ كرر بكتم الأداة. | muted لا يتغير مع إعدادات النص أو اللون غير المرتبطة بالكتم. |
| الألوان والفلاتر | بدّل عادي/عالي/داكن/رمادي/فلاتر؛ اختبر صيغة توكنات المشروع ثم مرر المحتوى والحوار. | لا أوضاع متعارضة، وألوان CSS صالحة، والحوار والدليل ثابتان خارج الفلاتر. |
| التباين | قِس النصوص والحدود والتركيز على خلفيات الموقع في كل وضع مع عناصره الحقيقية. | أدلة قياس فعلية؛ لا تُستنتج مطابقة شاملة من نتيجة axe. |
| قارئ الشاشة | اقرأ الفتح والحوار والإعدادات والقيم والخلفية والإغلاق بقارئ فعلي. | أسماء وحالات مفهومة وتركيز صحيح، وإعلانات موثقة؛ غياب القارئ = غير مختبر. |
| التسميات والاعتماديات | راجع الأسماء والرسائل والخطوط والفلاتر ومكتبات البناء. | لا ادعاء طبي أو خط خاص غير موجود، ولا اعتماد غير ضروري على React/Tailwind. |

## قالب نتيجة التكييف

```text
التقنية والإصدارات:
نظام CSS وطريقة العرض:
المتصفحات والعروض والتكبير:
قارئ الشاشة والصوت الحقيقي المتاح:
الملفات والاعتماديات والتغييرات:
الحالة | النجاح/الفشل/غير المختبر | خطوات التكرار | الدليل | الحدود أو العائق
```

افصل نتائج هذا الجدول عن نتائج React V5 التاريخية. عند تحديث مرجع React نفسه، سجّل سبب التغيير وأعد اختبارات السلوك المتأثر؛ عند تعديل التوجيهات فقط تحقق من الروابط والحزمة ولا تدّع اختبار تنفيذ جديد.
