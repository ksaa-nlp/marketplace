# دمج الأداة مع موقع ميسّر

شريط التفضيلات أداة اختيارية. إتاحة الموقع تعتمد أيضًا على تصميم المحتوى وبنيته وسلوكه، وتحتاج تحققًا فعليًا.

- استخدم header وnav وmain وfooter، وتسلسل عناوين مفهومًا. النطق يقرأ main عند وجوده.
- أضف نصوصًا بديلة ذات معنى للصور، أو alt فارغًا للصور الزخرفية.
- استخدم label واضحًا لكل حقل، ووصفًا نصيًا للأخطاء لا يعتمد على اللون وحده.
- افحص تباين النصوص والحدود والتركيز في تصميم الموقع نفسه؛ الفلاتر لا تصلح تباينًا أساسيًا ضعيفًا تلقائيًا.
- تحقق من جميع الوظائف بلوحة المفاتيح، والتركيز المرئي وترتيبه وEscape في الحوارات.
- احترم prefers-reduced-motion في الموقع، وراجع الحركات والوميض.
- اضبط lang وdir على html، وافحص اللمس والتكبير وعرض 320px.

استخدم [وثيقة WCAG 2.2 الأصلية](https://www.w3.org/TR/WCAG22/) مرجعًا لمعايير الموقع التي تستهدفها، ولا تفترض تحققها من نجاح أداة تفضيلات أو فحص آلي محدود.

## حدود سلوك الأداة

لا تختطف التركيز خارج الحوار، ولا تكتب فوق دلالات محتوى الصفحة، ولا تعلن نفسها بصورة متكررة. inert وaria-hidden مؤقتان لعزل خلفية الحوار، ويجب استعادة حالتهما السابقة عند الإغلاق.

لا تصف الأداة كقارئ شاشة أو وضع طبي أو ضمان مطابقة. لا تتجاوز اختيارات الزائر الأخرى مثل كتم الفيديو عند تعديل حجم النص.

## وصف مناسب للنشر

«شريط تفضيلات إتاحة للمواقع العربية، مع أدوات اختيارية لتخصيص القراءة والمظهر والتنقل». أرفق قائمة الأدوات وحدودها وإصدارات المتصفحات وقارئات الشاشة التي اختُبرت فعلًا.
