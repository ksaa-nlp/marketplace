# شريط تفضيلات الإتاحة للمواقع العربية

إضافة `accessibility-toolbar` لسوق `ksaa-nlp`، مبنية على المصدر العام [arabic-accessibility-toolbar](https://github.com/haithamnaddaf/arabic-accessibility-toolbar) ومرخّصة بترخيص MIT مع حفظ نسبة المؤلف.

## المحتوى

- `skills/accessibility-toolbar/SKILL.md`: تعليمات المهارة بالعربية.
- `skills/accessibility-toolbar/assets/`: مكوّن React/CSS واختبارات المرجع الأصلية.
- `skills/accessibility-toolbar/references/`: مرجع التكييف وأفضل الممارسات وتقرير تحقق V5.
- `downloads/accessibility-toolbar-v5.zip`: الحزمة النهائية الأصلية ذات 12 ملفًا.
- `downloads/manifest.json` و`downloads/SHA256SUMS`: بيانات النسخة والبصمة.

## الاستخدام والحدود

اقرأ `SKILL.md` ومرجع `framework-adaptation.md` قبل الدمج. التنفيذ المختبر المرفق هو React؛ أما Vue وAngular وJavaScript وغيرها فهي إرشادات تكييف تحتاج اختبارًا مستقلًا. الشريط لا يجعل الموقع مطابقًا لـWCAG أو ADA، ولا يعالج بنية الموقع غير الميسّرة. وضع ADHD دليل قراءة وتقليل حركة اختياري وليس ادعاءً طبيًا.
