# Showing a consultation — المستشار اللغوي

For each consultation returned, and for each one in `referencedConsultations`, show all of:

- رقم الاستشارة ورابطها
- السؤال بنصه
- الإجابة بنصها كاملة — no summary, no correction
- اسم المستشار
- التصنيف والتصنيفات الفرعية والوسوم
- تاريخ السؤال وتاريخ الإجابة
- ملحوظة: «الإجابة تمثل رأي المستشار»

`matchType` tells you how close a result is: `exact` and `close` answer the same question;
`related` only touches it — say so.

If the platform is unreachable, give its support address: support-almustashar@ksaa.gov.sa.
