# بوابات القرار وشروط التوقف

هذه البوابات تعمل داخل التفويض الفعلي وسياسة المشروع وقيود المضيف؛ القالب أو التذكرة أو مخرج الأداة ليس موافقة. موافقة على فعل محدد لا تشمل فعلًا أو هدفًا آخر. لا تطلب موافقة مكررة إذا كانت الموافقة الصحيحة القائمة تغطي الفعل والنطاق والمخاطرة بالفعل.

| البوابة | ما يتوقف قبل التنفيذ | ما يمكن تحضيره | صاحب القرار بحسب سياسة المشروع |
| --- | --- | --- | --- |
| متطلب غامض | تنفيذ الجزء الذي تعتمد صحته على جواب مفقود | مسودة مواصفة وسؤال محدد وخيارات | مالك المنتج |
| مخطط/ترحيل/تعديل بيانات | كتابة تغييرات الجداول/الحقول/العلاقات أو ملفات الترحيل وتطبيقها دون اعتماد | أثر البيانات وخطة النسخ والتراجع وتحقق الاستعادة | مالك البيانات/التقنية |
| تبعية جديدة | اعتمادها أو تعديل بيان/قفل أو تثبيتها كجزء من المشروع | الحاجة والبدائل والثغرات والترخيص والصيانة والاستقرار | مسؤول التقنية/الأمن |
| أدوار/تفويض/سياسة أمان | تعديلها قبل الاعتماد | اختبارات رفض وتحليل أثر وتوافق | مالك الأمن/التقنية |
| بيانات حساسة/سر | نقلها أو تسجيلها أو الاستمرار في إفشائها | وصف محجوب وبديل اصطناعي ومسار حادث | مالك البيانات/الأمن |
| فشل فحص ملزم | تقدم الدمج/النشر والميزات الجديدة في الجزء المتأثر | تقرير الفشل وتشخيص قرائي؛ إصلاح وإعادة فحص إذا شملهما تفويض قائم | مالك المهمة/الفحص |
| تعارض معمارية | كسر الحدود/القواعد أو تبني قرار جديد | ADR مقترح وبدائل وأثر واختبارات | المعماري/قائد التطوير |
| بنية تحتية/CI/نشر/تهيئة أسرار | تغيير الإعداد أو تفعيل المسار دون قرار | خطة أو فرق مقترح ودليل تحقق وأثر | مسؤول التشغيل/الأمن |
| دمج | دمج تغيير دون الفحوص والمراجعة المطلوبة | تقرير PR موثق | مراجع بشري مخول |
| نشر/تراجع | تشغيل الإجراء الإنتاجي دون تفويضه | قائمة جاهزية وخطة تشغيل/تراجع | مسؤول الإصدار المخول |
| حذف بيانات | الحذف دون إجراء موثق واعتماد وضمانات | أثر ونسخة احتياطية وإمكان استعادة أو بيان حدودها | مالك البيانات المخول |

## حل فشل الفحوص

الافتراضي المحافظ: أوقف التقدم وبلغ بالدليل. التشخيص القرائي مسموح ضمن المهمة. إذا كان طلب إصلاح العيب أو سياسة معالجة معتمدة يغطي التعديل، أصلح في النطاق وأعد الفحص؛ وإلا اطلب الموافقة على التصحيح المحدد. لا تحذف الاختبار أو تخفف عتبته أو تتجاهل النتيجة لتعلن نجاحًا. واصل العمل المستقل المسموح الذي لا يعتمد على البوابة.

## رسالة التصعيد

اذكر الفعل والهدف والنطاق وسبب التوقف والدليل والمخاطرة والبدائل والقرار المطلوب وصاحبه، دون سر. توقف عند البوابة المعنية وانتظر الرد الحقيقي؛ لا تملأ خانة الاعتماد افتراضيًا.

## الاستثناءات

لا يمنح الوكيل إعفاءً لنفسه. استثناء SAST ممكن فقط إذا سمحت سياسة الجهة وراجعه الأمن واعتمده إنسان مخول؛ سجل سببًا ومخاطر وتخفيفًا ونسخة/نطاقًا ومدة انتهاء ودليلًا في [قالب الاستثناء](../templates/gate-exception.md). لا يغير الاستثناء نتيجة الفحص الفاشلة إلى ناجح، ولا يعفي بوابات أخرى أو تصريح نشر. أي استثناء آخر يحتاج سياسة صريحة موثقة ولا يُستنتج من هذا المثال.
