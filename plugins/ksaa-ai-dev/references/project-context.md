# اكتشاف محلي بلا افتراض معمارية

هذا الدليل أسئلة اكتشاف عامة، وليس سجلًا لمستودع خاص أو وصفًا لبنية منتج بعينه. أمثلة أسماء الملفات والأدوات احتمالات؛ وجودها وسلطتها وأوامرها تثبت في المستودع الحالي.

## ما تقرأه قبل التنفيذ

- تعليمات النطاق: `AGENTS.md` وما تشير إليه؛ محولات الأداة مثل `CLAUDE.md` عند وجودها؛ لا تجعل تكرار القواعد مصدرين متعارضين ولا تنسخ تعليمات السوق إلى المنتج.
- README ودليل المساهمة والأمان والمعمارية وفهرس المواصفات المحلي والتذكرة ومعايير القبول. حدد مرجع السلوك والمالك، ثم التنفيذ والاختبارات والفجوات المعروفة؛ لا تخترع مسار مواصفات.
- ملفات workspace والحزم وأدوات البناء والاختبار وCI وملفات التهيئة التي تشير إليها. قد تكون وظيفة اختبار معرفة لكن ملف تهيئتها مفقودًا؛ تحقق من وجوده ونطاقه قبل اعتمادها.
- نقطة تشغيل الواجهة أو الخدمة أو اللعبة والمتغير البنائي المتأثر، والعقود ومولداتها والمستهلكون. الإصدارات والأطر وأوامر التشغيل تُكتشف لكل حزمة؛ لا تفرض مكدسًا أو إصدارًا موحدًا.

## ملف السياق المحلي

استخدم [ملف المشروع](../templates/project-profile.md) لتسجيل مصدر كل حقيقة مع نسختها. لا تضع هذه التفاصيل في حزمة المهارات العامة. عند تغير حدود المكونات استخدم [خريطة المعمارية](../templates/architecture-context.md).

| القدرة المكتشفة | أسئلة عملية للمهمة |
| --- | --- |
| لعبة داخل تطبيق أو بمحرك مستقل | أين الدخول وحالة الجولة وقواعد النتيجة ومصدر الأسئلة؟ هل توجد نتائج محفوظة أو ترتيب أو لعب متزامن فعليًا؟ |
| معجم أو تحرير محتوى | ما السجل الأصلي؟ كيف تراجع/تنشر النسخة إن كانت الدورة مدعومة؟ من يقرأ المورد ويعدله؟ |
| مدونة لغوية وبحث | ماذا يعني الاستعلام والفلاتر والسياق؟ ما حقوق النص والبيانات الوصفية والتصدير؟ |
| صفحة عامة | ما العقد ومصدر البيانات؟ هل تدعم RTL وSSR والمحمول وروابط مباشرة؟ اختر ما يتأثر فقط. |
| API أو عقد مولد | أين العقد ومولده وإصداره ومستهلكوه؟ هل توثيق المدخلات مصحوب بتحقق فعلي وقت التشغيل؟ |

## فحص الأمر قبل تنفيذه

سجل الأمر ومجلد عمله ومصدره وأثره وبيئته. قد يعدل `lint --fix` أو formatting الملفات، وقد ينشر build، أو يستخدم الاختبار قاعدة خارجية. لا تحذف علمًا أو تضف خيارًا عشوائيًا؛ اشتق صيغة الفحص من الأداة المعتمدة. إذا تعذر تحقق العزل توقف عن التشغيل المؤثر واكتف بالقراءة.

افصل أربع حالات: **معرف في الإعداد**، **ملفاته موجودة**، **نُفذ على هذه النسخة**، **نجح بدليل**. اختبار الوحدة أو الخادم لا يثبت تفاعل المتصفح أو الجهاز. احتفظ بفجوات البيئة والأداة والمتغير البنائي في التسليم.
