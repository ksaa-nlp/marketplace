# ksaa-ai-dev: حوكمة التطوير بمساعدة AI

إضافة مستقلة تضم 16 مهارة عربية للمواصفات والتخطيط والتنفيذ والاختبار والمراجعة وجاهزية الإصدار. تشمل سيناريوهات عملية للمعاجم والمدونات اللغوية والألعاب التعليمية، وتكتشف تفاصيل كل مستودع محليًا بدل نشر خرائط المشاريع الخاصة.

المهارات تعليمات عمل، وليست خدمة تعمل في الخلفية أو نظام صلاحيات. لا تتضمن hooks أو خادم MCP أو مفاتيح أو تبعيات برمجية خارج مكتبة Python القياسية للفحوص الاختيارية. تثبيتها لا يفعّل CI أو حماية فرع أو sandbox ولا يعتمد سياسة مؤسسة.

## 1. التثبيت

بعد نشر هذا الإصدار في السوق، افتح Claude Code داخل مستودع المنتج واكتب:

```text
/plugin marketplace add ksaa-nlp/marketplace
/plugin install ksaa-ai-dev@ksaa-nlp
```

راجع الإضافة واختر نطاق التثبيت المناسب في الواجهة. تحقق من ظهورها في `/plugin` ومن المهارة `/ksaa-ai-dev:ksaa-context` عند كتابة `/`. اتبع رسالة التفعيل أو إعادة التحميل التي يعرضها إصدارك. هذه الخطوات موثقة في [دليل Claude Code الرسمي](https://code.claude.com/docs/en/discover-plugins).

### تجربة النسخة المحلية قبل النشر

من جذر نسخة السوق المحلية، وفي بيئة تجريبية مسموحة:

```bash
claude --plugin-dir ./plugins/ksaa-ai-dev
```

هذا يحمل الإضافة في الجلسة للتجربة وفق [دليل الإضافات الرسمي](https://code.claude.com/docs/en/plugins). لا يثبت نجاح استدعاء المهارات حتى تجربها. للتجربة داخل منتج آخر استخدم المسار المطلق لنسختك المحلية بدل المسار النسبي؛ لا تنسخ بيانات المنتج إلى الإضافة.

### التحديث والإزالة

التحديث التلقائي للسوق المخصص قد يكون معطلًا. راجع `/plugin` ثم `Marketplaces`؛ للتحديث اليدوي حدّث فهرس السوق داخل الجلسة:

```text
/plugin marketplace update ksaa-nlp
```

ثم من الطرفية:

```bash
claude plugin update ksaa-ai-dev@ksaa-nlp
```

يمكن تعطيل الإضافة أو إزالتها من `/plugin`. راجع [إدارة التحديثات](https://code.claude.com/docs/en/discover-plugins#keep-plugins-updated) لإصدارك. هذه الإضافة لا تستبدل `dga-design` ولا تعليمات المستودع.

## 2. بداية عملية

ابدأ داخل مستودع تملك صلاحية العمل فيه:

```text
/ksaa-ai-dev:ksaa-context حدد تعليمات هذا المستودع ومواصفاته وأوامر فحوصه وأثرها. المهمة: تحسين البحث العربي. لا تعدل ملفات.
```

إذا كان الطلب غير واضح:

```text
/ksaa-ai-dev:ksaa-spec صغ مواصفة لتجربة بحث عربية من التذكرة المرفقة. ميز القواعد المثبتة عن الأسئلة، ولا تفترض إزالة التشكيل أو الهمزات.
```

بعد وضوح المواصفة واعتماد القرارات اللازمة:

```text
/ksaa-ai-dev:ksaa-plan قسم معايير القبول المعتمدة إلى مهام واختبارات وقرارات، دون كتابة كود.
/ksaa-ai-dev:ksaa-build نفذ المهمة المحددة في الفرع الحالي ضمن النطاق المصرح. سجل الفحوص الفعلية، وتوقف عند تغيير غير معتمد للبيانات أو الصلاحيات أو التبعيات.
```

أمثلة مراجعة محدودة:

```text
/ksaa-ai-dev:ksaa-game-qa راجع لعبة الكلمات المتأثرة: زمن الصفر، الضغط المكرر، إعادة الجولة، تنظيف المؤقتات وRTL. لا تفترض وجود لعب شبكي أو حفظ نتائج.
/ksaa-ai-dev:ksaa-language-qa اختبر البحث والعرض باستخدام بيانات اصطناعية وقاعدة التطبيع المعتمدة. افصل صحة اللغة عن نجاح الاستعلام.
/ksaa-ai-dev:ksaa-review راجع فرق التغيير الحالي مقابل المواصفة والاختبارات. اذكر النواقص والموانع، ولا تدمج أو تنشر.
```

المخرجات المعتادة: حقائق مع مصادر محلية، أسئلة مانعة، معايير قابلة للاختبار، فرق محدود إن طلب، نتائج بأوامر ونسخة وبيئة، ومراجعة بشرية معلقة أو موثقة. لا يلزم استدعاء المهارات الست عشرة لكل مهمة؛ اختر ما يغير القرار أو التحقق فعلًا.

## 3. اختيار المهارة

| [ksaa-release](skills/ksaa-release/SKILL.md) | جاهزية نسخة للإصدار | أدلة وتراجع وموافقة، دون نشر |
| [ksaa-measure](skills/ksaa-measure/SKILL.md) | تقييم جودة أو تجربة | مؤشرات بمصادر، لا ادعاء سببية |

## 4. ما يقره الفريق قبل الاستخدام المؤثر

تبقى القرارات التالية مفتوحة حتى توثق في المشروع: الأدوات والبيانات المعتمدة، أصحاب اعتماد المتطلبات والمعمارية والأمان، نطاق البيئة والصلاحيات وانتهاؤها، الفحوص وعتباتها وحمايتها، سياسة الإصلاح بعد فشل، والاستثناءات الممكنة ومدتها، والنشر والتراجع والاحتفاظ بالسجلات. لا يملأ الوكيل هذه الفراغات بموافقات مفترضة.

اقرأ [ضوابط الحوكمة](references/governance-controls.md) و[بوابات القرار](references/decision-gates.md) و[البوابات الثماني](references/quality-gates.md). قوالب البداية:

- [سياسة AI](templates/ai-policy.md) و[تفويض الوكيل](templates/agent-access.md) و[سجل الاستخدام](templates/ai-usage-log.md)
- [مواصفة الميزة](templates/feature-spec.md) و[تتبع المعايير](templates/traceability.md) و[مصفوفة الاختبار](templates/test-matrix.md)
- [خريطة المعمارية](templates/architecture-context.md) و[ADR](templates/adr.md)
- [مراجعة PR](templates/pr-review.md) و[مراجعة الأمان](templates/security-review.md) و[استثناء بوابة](templates/gate-exception.md)

القوالب أمثلة قابلة للتكييف وليست ملفات تُنسخ تلقائيًا. المراجع داخل الإضافة ولا تتطلب مهارة خارجية أو وصولًا إلى مستودع خاص. احتفظ بملف السياق المعبأ وأدلة المشروع داخل وجهته المصرح بها؛ لا تنشره في السوق العام.

## 5. فحوص المساهمين

من جذر السوق؛ Python 3.8 أو أحدث، بلا شبكة أو تثبيت حزم:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 plugins/ksaa-ai-dev/scripts/validate-plugin.py
PYTHONDONTWRITEBYTECODE=1 python3 plugins/ksaa-ai-dev/scripts/run-tests.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s plugins/dga-design/tests -v
```

لإثبات المحافظة على نسخة سوق سابقة، مرر مسار نسخة نظيفة لها:

```bash
python3 plugins/ksaa-ai-dev/scripts/validate-plugin.py --baseline ./baseline-marketplace
```

يتجاهل الفحص ملفات Python المؤقتة ومجلد Git. يفحص الخيار عدم حذف/تغيير ملفات النسخة السابقة عدا إضافات README وتسجيل السوق ورفع نسخته. ضع نسخة المقارنة خارج الشجرة المنشورة.

عند توفر Claude Code، شغّل أيضًا الفحص الرسمي:

```bash
claude plugin validate .
```

الفحص المحلي يدعم مجموعة YAML ضيقة عمدًا: `name` باسم kebab-case و`description` سلسلة JSON مقتبسة صالحة داخل YAML. يرفض حقولًا/صياغات إضافية بدل ادعاء تحليل YAML كامل. يفحص التسجيل والإصدارات وروابط الموارد وحدودها وإشارات خصوصية عامة؛ ليس ماسح أسرار شاملًا ولا بديلًا عن المراجعة البشرية أو فحص Claude الرسمي. الاختبارات السلبية تغطي أوصافًا غير مقتبسة ذات نقطتين، نسخًا غير متطابقة، موارد مفقودة، خروج روابط، تغيير المحتوى السابق، وسجلات أدلة ناقصة أو متناقضة.

### فحص سجل البوابات

انسخ [السجل الفارغ](templates/gate-evidence.json) إلى مساحة محلية مصرح بها واملأه من نتائج حقيقية، ثم:

```bash
python3 plugins/ksaa-ai-dev/scripts/check-gate-evidence.py ./gate-evidence.json
```

السجل الفارغ يخرج بفشل مقصود. الخروج صفرًا يعني اتساق حقول معلنة فقط؛ الأداة لا تتحقق من هوية مراجع أو صحة تقرير أو حماية حية ولا تمنح إذنًا للدمج/النشر. الاستثناء المحافظ المدعوم SAST فقط بسياسة ومراجعة أمنية واعتماد ومدة محددة؛ تبقى النتيجة الأصلية فاشلة.

## 6. حدود التحقق

اختبارات التغليف والأدلة لا تشغّل Claude ولا تطبيقًا ولا متصفحًا ولا محاكيًا، ولا تثبت أن النموذج التزم بالتعليمات. نفّذ [التجارب السلوكية](references/behavioral-checks.md) في بيئة اصطناعية معزولة وسجل نتائجها منفصلة؛ السيناريو المكتوب ليس اختبارًا ناجحًا. يجب إثبات التثبيت والاستدعاء والضوابط التقنية والاختبارات الخاصة بالمنتج في البيئة التي ستستخدمها.
