# اكتشاف السياق قبل التنفيذ

1. اقرأ تعليمات المستودع الحالية، والتذكرة، ودليل المساهمة والمواصفات والعقود المتعلقة بالمهمة وفق [دليل الاكتشاف](../../references/project-context.md). احتفظ بالتعليمات القائمة؛ لا تستبدلها بقالب السوق.
2. اكتشف ملفات workspace وبيانات كل حزمة، لا ملف الجذر وحده. حدّد النسخة والفرع وحالة التغييرات ومكان الكود والاختبارات والمتغير البنائي المعني: عام، إدارة، محمول، علامة تجارية أو SSR إن وجد.
3. افحص نص أوامر البناء والاختبار وlint قبل تشغيلها: قد يحتوي lint على `--fix` أو قد تتصل الاختبارات ببيئة خارجية. ميّز أمرًا معرفًا من أمر نُفذ ومن نتيجة ناجحة؛ اختبار الخدمة لا يثبت رحلة المتصفح.
4. املأ [ملف سياق المشروع](../../templates/project-profile.md) بالقدر اللازم. صنف المعلومة: مرصودة مع دليل، مطلب جديد، اقتراح، أو غير متحقق. وجود نموذج للنتيجة أو اللاعبين لا يثبت لعبًا شبكيًا أو ترتيبًا دائمًا.
5. حدد الحد الأدنى للمواصفة والبيئة الآمنة والصلاحيات. إن غاب معيار جوهري أو كانت البيئة غير متحققة، اقترح الخطوة الآمنة والسؤال المانع دون بدء تنفيذ تخميني.

**المخرج:** خريطة سياق مختصرة، أوامر موثقة بمكان العمل وأثرها، فجوات وقرارات. تبقى مسارات وحقائق المشروع الخاص داخل قنواته المعتمدة؛ لا تنقلها إلى هذه الإضافة العامة.
