# توثيق يطابق الواقع

1. حدد مصدر الحقيقة الحالي للمواصفة والعقد والتوثيق عبر [دليل السياق](../../references/project-context.md). لا تكتب نسخة عقد يدوية تنافس مولد المشروع أو تستبدل تعليماته القائمة.
2. طابق فرق السلوك مع المتطلب ومعايير القبول والصلاحيات والبيانات والنسخة. حدث الوثائق المتأثرة في التغيير نفسه أو سجل سبب عدم الحاجة؛ لا تغير معيارًا لإخفاء عيب أو تحذف فجوة باقية.
3. ميّز منفذًا ومقترحًا ومؤجلًا وغير متحقق. اربط قرارات المعمارية بحالتها الحقيقية، وراجع أوامر README وأمثلتها دون تشغيل أمر مؤثر لمجرد أنه مكتوب.
4. افحص الروابط المحلية والمراجع والأمثلة ودليل النتيجة عند الإمكان. لا تنقل كودًا أو مسارات أو تهيئة أو معمارية أو روابط خاصة إلى وثيقة عامة؛ استخدم ملف سياق محلي وقنوات المشروع المعتمدة.
5. قدم أثر التوثيق وسجل مساهمة AI في [سجل الاستخدام](../../templates/ai-usage-log.md) دون نصوص حساسة. إذا تطلب النشر مشاركةً خارجية، توقف عند مسار الموافقة المناسب.

**المخرج:** ملفات التوثيق وأسبابها، روابط تحقق، حدود ما اختُبر وفجوات صريحة.
