# قياس نتائج وتحسين محدود

1. حدد المنتج والفترة والهدف وخط الأساس ومصدر كل رقم عبر [قالب القياس](../../templates/quality-metrics.md). غياب المصدر يسجل بيانات ناقصة، لا صفرًا ولا نسبة مختلقة.
2. اختر مؤشرات نتيجة مناسبة: زمن التسليم، عيوب ما بعد الإصدار وشدتها، تغطية المعايير الحرجة، زمن مراجعة PR، التراجع والتعافي، قابلية الصيانة ورضا الفريق إذا وجدت بياناته. اربطها بنجاح رحلة المستخدم أو صحة البحث أو استقرار اللعبة بحسب النطاق.
3. ثبت تعريف البسط والمقام والفترة وحجم العينة ونسخة المنتج وتغير الأدوات. لا تفسر الارتباط سببية أو كثرة الأسطر/المطالبات تحسنًا. لا تجمع بيانات شخصية أو آراء فريق من دون تفويض.
4. عند طلب تقييم النضج، افصل الممارسة المرصودة عن الهدف: استخدام فردي، سياق ومواصفات، بوابات ومراجعات، ثم قياس مؤسسي. لا تمنح شهادة امتثال من وجود قوالب.
5. اقترح إجراء تحسين قابلًا للقياس، ومالكًا وتاريخ مراجعة، وحدود ثقة وفجوات. لا تنشئ متابعة دورية أو إرسالًا خارجيًا تلقائيًا لمجرد اقتراحها.

**المخرج:** تعريفات وقيم بمصادرها وحدودها، مقارنة حذرة، وإجراء تحسين محدود.
