# سجل تفويض وبيئة الوكيل

هذا سجل مقترح أو موثق، وليس منحًا تقنيًا للوصول.

| البند | القيمة المتحققة |
| --- | --- |
| الوكيل والغرض والتذكرة | `[اسم ودور ونطاق]` |
| الملفات/الموارد المسموحة | `[أقل نطاق، قراءة/كتابة منفصلتان]` |
| الأدوات المسموحة | `[أداة وفعل وهدف]` |
| الأدوات والأفعال المحظورة | `[نشر/حذف/تعديل صلاحية/غيره وفق السياسة]` |
| البيانات المسموحة ومصدرها | `[اصطناعية وتصنيف ورابط سياسة]` |
| البيئة المسموحة | `[هوية ودليل عزل عن الإنتاج]` |
| الموافقات المطلوبة وصاحبها | `[فعل ومالك ودليل؛ المفقود صريح]` |
| السجلات والمراقبة | `[ما يسجل دون أسرار ومن يراجعه]` |
| بداية الوصول وانتهاؤه | `[وقت أو شرط انتهاء، لا نطاق دائم مفترض]` |
| إمكان إعادة التهيئة | `[طريقة آمنة ودليل]` |
| غياب أسرار/وصول الإنتاج | `[طريقة تحقق آمنة أو غير متحقق]` |
| شروط التوقف والتصعيد | `[شروط وقناة ومالك]` |

**الحالة:** مسودة / معتمد / مرفوض / منتهي.
**اعتماد بشري حقيقي:** `[من ومتى ونطاق ومرجع، لا تملأ افتراضيًا]`.
**أذونات المضيف/المستودع الفعلية:** `[دليل؛ لا يكفي هذا السجل لإثباتها]`.
