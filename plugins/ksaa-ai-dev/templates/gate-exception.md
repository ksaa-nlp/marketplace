# استثناء بوابة محدود

لا تستخدمه إلا إذا سمحت السياسة المعتمدة؛ المثال المدعوم استثناء SAST بمراجعة أمنية. لا يعيد تسمية نتيجة فاشلة إلى ناجحة.

- البوابة والنتيجة الأصلية ودليلها: `[قيمة]`
- المشروع والنسخة والنطاق المتأثر: `[محدد]`
- سبب الاستثناء والمخاطرة: `[محدد]`
- البدائل والتخفيف وشروط الإلغاء: `[قابلة للفحص]`
- سياسة تسمح به: `[مرجع]`
- المراجع الأمني والإنسان المخول ودليل القرار: `[حقائق أو غير معتمد]`
- البداية والانتهاء: `[توقيت محدد]`
- مالك المعالجة وخطتها وموعدها: `[قيم]`
- حالة الاستثناء: `[مسودة/معتمد/منتهي/ملغى]`.

لا يعفي بقية البوابات أو يمنح تفويضًا بالنشر أو وصولًا دائمًا.
