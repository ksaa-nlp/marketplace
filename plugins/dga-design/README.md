# dga-design

مهارة تطابق تصميم أي مشروع ويب مع **كود المنصات**، نظام التصميم الوطني الموحد الصادر عن هيئة الحكومة الرقمية: https://design.dga.gov.sa/

## الاستعمال

بعد تثبيت الإضافة (`/plugin install dga-design@ksaa-nlp`):

```
/dga-design:dga-design audit            ← تقرير مطابقة فقط، بلا تعديل
/dga-design:dga-design                  ← تدقيق، ثم خطة، ثم موافقة، ثم تطبيق
/dga-design:dga-design apply src/pages  ← على نطاق محدد
```

ويستدعيها Claude تلقائيًا إذا طلبت مطابقة معايير DGA أو كود المنصات.

## ما تفعله

1. تفهم المشروع (المكدس، وطريقة الأنماط، ونوع المنصة) من `AGENTS.md` والملفات.
2. تدقّق آليًا بـ `scripts/audit.py`: الألوان خارج اللوحة (مع أقرب رمز)، والخطوط، والمسافات والحواف والأحجام خارج السلالم (px وrem و`clamp()`)، والظلال وتمويه الخلفية، وقيم Tailwind الاعتباطية، و`lang`/`dir`. ثم تراجع يدويًا بنود قائمة التحقق الرسمية الـ56.
3. تعرض خطة، وتسأل عن القرارات المعمارية (إضافة الحزمة، أو تغيير البناء).
4. تطبّق بالترتيب: الرموز، ثم القيم، ثم التخطيط، ثم المكونات، ثم هيكل الواجهة، ثم الأنماط، ثم الوصول.
5. تتحقق (التدقيق مرة ثانية وفحوص المشروع)، وتقدم تقريرًا بأرقام بنود القائمة.

## المصادر (كلها رسمية)

| المصدر | ما أُخذ منه |
|---|---|
| موقع https://design.dga.gov.sa/ | نصوص الإرشادات وجداول الأساسات والمكونات والقوالب |
| قائمة التحقق `https://design.dga.gov.sa/assets/updated-checkList.xlsx` | البنود الـ56 وأولوياتها |
| الحزمة `@platformscode/core@0.0.52` (npm، ترخيص MIT) | ملف الرموز `assets/dga-tokens.css` ومواصفات المكونات |
| الحزمة `platformscode-new-react@0.1.45` | أسماء مكونات React |

تعارضات المصدر (مثل أخطاء عمود rem في جدول المسافات) موثقة في آخر `skills/dga-design/references/foundations.md`، والقاعدة فيها: قيم الحزمة هي المرجع.

## الصيانة

- **تحديث الرموز** عند صدور إصدار جديد من الحزمة:
  ```bash
  python3 scripts/sync_tokens.py            # أحدث إصدار
  python3 scripts/sync_tokens.py 0.0.53     # إصدار محدد
  ```
  يحتاج `npm`، ثم راجع الفرق (`git diff`)، وحدّث رقم الإصدار في المراجع، وارفع `version` في `plugin.json`.
- **الاختبارات** (بلا شبكة):
  ```bash
  python3 -m unittest discover -s tests
  ```
- عند تغيّر قائمة التحقق في موقع DGA: نزّل الملف، وقارنه بـ `references/checklist.md`.
